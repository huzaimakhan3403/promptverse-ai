Prompt engineering · Beginner guide

How to Write a Clear AI Prompt: Role, Context, Task and Format

A useful prompt gives an AI assistant enough information to understand the job without making the request unnecessarily complicated. One practical structure is Role, Context, Task and Format (RCTF). The role describes the perspective you want the assistant to take. Context explains the situation, audience and constraints. The task states the action. The format tells the assistant how to organise its answer.

Example you can adapt

Role: Act as an experienced science tutor.
Context: I am a beginner learning photosynthesis for a school exam.
Task: Explain the process, why sunlight matters, and two common misconceptions.
Format: Use simple language, numbered steps and a short five-question quiz.

Start with a narrow task, then add details only when they improve the result. If the answer is too advanced, ask for a simpler explanation and specify what you already understand. If it is too broad, divide the work into smaller steps. For factual subjects, ask for sources you can independently check rather than treating generated citations as automatically correct.

Before using the result, check whether it follows your instructions, covers the intended audience and makes unsupported claims. RCTF is a helpful checklist, not a guarantee of accuracy. Browse the prompt library for starting points you can customise.

Image generation · Practical workflow

Build Better AI Image Prompts with Subject, Setting, Lighting and Composition

Image-generation systems respond more consistently when the prompt describes the visual scene in a logical order. Begin with the main subject, then describe the setting, action, visual style, lighting, camera perspective and composition. Include only details that matter to the image you want; a long list of conflicting adjectives can make the result less predictable.

A reusable example

A small ceramic coffee cup on a wooden table beside a rainy window, quiet morning atmosphere, soft natural window light, warm neutral colour palette, close-up product photography, shallow depth of field, clean composition with empty space on the left.

If the first image is close but not correct, change one variable at a time. For example, keep the subject and composition fixed while changing the lighting from soft daylight to dramatic side lighting. This makes it easier to understand which instruction affected the output. Aspect ratios and other settings differ by platform, so check the image tool's current documentation.

Avoid relying on a style name alone when the visual requirements are important. Describe visible characteristics such as contrast, colour, texture and framing. Review generated images for distorted text, unwanted objects and details that could misrepresent a real person or product.

Writing workflow · Editing checklist

Use AI to Draft and Edit Content Without Losing Your Own Voice

AI can help organise ideas, create an outline or identify unclear sentences, but a useful publishing workflow still needs human judgement. Start by writing down the reader's question and the specific value your article will provide. Ask the tool for an outline, review the structure, and then draft each section using your own expertise, examples and research.

Editing prompt example

Review the text below for clarity, logical order and grammar. Preserve my meaning and personal tone. Do not add facts, statistics or quotations. Return (1) a lightly edited version and (2) a short list explaining the most important changes. Mark anything that needs fact-checking.

Check names, dates, statistics, quotations and links against reliable sources. Remove generic filler and add concrete examples that reflect the intended audience. Make sure headings accurately describe the sections below them. If you use AI-generated text, images or code, review the result for originality, accuracy, permissions and suitability before publishing.

The final article should answer the reader's question better than a generic summary. Add your own testing notes, comparisons, limitations or lessons learned where relevant. Do not publish an unreviewed draft simply because it reads smoothly.

Prepare Clean Text Before Using an AI Assistant

Copied text often contains repeated spaces, inconsistent line breaks, formatting fragments or unrelated notes. Cleaning the input before sending it to an AI assistant makes the task easier to read and can reduce avoidable confusion. It does not automatically make the model more accurate, but it helps you provide a clearer source.

A simple preparation routine

  1. Keep the original document as a backup.
  2. Remove duplicated spaces and accidental blank lines.
  3. Separate instructions from the source material.
  4. Label tables, headings and quoted passages clearly.
  5. Remove personal or confidential information that the tool does not need.
  6. Check the cleaned text against the original before using it.

For example, instead of pasting a long unlabelled email thread and asking “summarise this”, state whether you need decisions, action items, deadlines or unresolved questions. If the text includes multiple speakers, preserve speaker labels so the summary does not confuse who said what.

PromptVerse includes browser-based text utilities for common preparation tasks. Avoid pasting passwords, financial details or sensitive personal records into any online service unless you have checked its privacy and security practices.

Evaluation · Responsible AI use

How to Check an AI-Generated Answer Before You Use It

A confident tone is not proof that an AI answer is correct. Models can omit context, make arithmetic mistakes, produce outdated information or invent references. Treat generated output as a draft that needs review, especially when it may affect health, money, legal rights, safety, employment or important business decisions.

Five checks to perform

  1. Source check: open cited sources and confirm that they support the claim.
  2. Date check: verify that prices, rules, software instructions and statistics are current.
  3. Logic check: test calculations and look for contradictions.
  4. Context check: confirm that the answer applies to your location, audience and situation.
  5. Risk check: ask a qualified professional when the decision requires specialist advice.

You can ask an assistant to list assumptions, identify uncertain points and suggest ways to verify them. That can make review easier, but it does not replace independent checking. Do not treat an AI system as the final authority for high-impact decisions.
