First-time setup

  1. Sign in to Pages CMS using the GitHub account that can access the PromptVerse repository.
  2. Authorize Pages CMS to access huzaimakhan3403/promptverse-ai.
  3. Open the Blog Articles collection.
  4. Create an article, add its SEO details and featured image, then save. Keep Keep as draft enabled until ready to publish.
  5. When you save a published article, GitHub receives the content and Vercel should rebuild the website automatically.

Security: Never share your GitHub password or access token. Sign in only through the official Pages CMS website and review the permissions requested during authorization.
