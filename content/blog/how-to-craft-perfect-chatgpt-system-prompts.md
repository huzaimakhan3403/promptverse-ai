A strong system prompt gives an AI assistant a clear job, useful context and boundaries. It cannot guarantee perfect answers, but it can make results more consistent and easier to evaluate.

## What is a system prompt?

A system prompt is a set of high-level instructions that shapes how an AI assistant behaves. It can define the assistant’s role, goals, tone, constraints and response format across a task or conversation.

## The six parts of a reliable prompt

Start with a role, then state the task and desired outcome. Add relevant context about the audience or situation. Define rules and boundaries, including what to do when information is missing. Specify the output format, and add examples when the expected result is hard to describe.

## A reusable template

- **Role:** [assistant role]
- **Goal:** [desired outcome]
- **Context:** [background]
- **Instructions:** [steps and rules]
- **Constraints:** [limits]
- **Output:** [format, length and tone]
- **Clarification:** [what to ask when information is missing]

Replace each bracket with task-specific details.

## Use examples to reduce ambiguity

A short example of a good answer can communicate structure and tone more clearly than a long list of adjectives. Include input and expected output when formatting matters. Avoid examples that introduce unrelated facts or requirements.

## Test and improve your prompt

Try representative tasks and edge cases. Check accuracy, completeness, consistency and formatting. Make repeatedly missed requirements explicit, then retest against the same examples after each revision.

## Mistakes to avoid

Avoid vague requests such as “be smart,” conflicting rules, invented sources and unsupported certainty. For important decisions, require uncertainty to be stated and verify claims independently.

## Key takeaway

A useful system prompt is specific, testable and focused on the outcome. Define the role, task, context, constraints and output format, then improve it through repeated testing.
