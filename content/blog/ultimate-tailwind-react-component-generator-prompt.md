Copy and paste this prompt into ChatGPT or Claude to build high-performance frontend components instantly:

```text

1. Clean, modular code with proper component structure.

2. Fully responsive design (mobile-first approach).

3. Modern dark-mode styling with smooth hover transitions, subtle borders, and glassmorphism accents.

Provide the complete code snippet along with short customization instructions.
```
